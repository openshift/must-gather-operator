# Code of Conduct

This project follows the [Kubernetes Community Code of Conduct](https://git.k8s.io/community/code-of-conduct.md) (CNCF).

Report CoC incidents as described in that document. Do not use a public GitHub issue for harassment or security reports. Security vulnerabilities go to [Red Hat Product Security](https://access.redhat.com/security/team/contact); see [SECURITY.md](SECURITY.md).
